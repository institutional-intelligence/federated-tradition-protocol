# キツネ教

**キツネ教 — キツネの信仰**

> 「BABYMETALの音楽が在る。ゆえに神は在らねばならぬ。」

キツネ教は、BABYMETAL、キツネの象徴、神道、東方正教会、そしてメタル・レジスタンスの神話に着想を得た、構築された宗教伝統である。

キツネ教は、音楽、儀礼、象徴、神話、共同体としての本質、そして宗教的表現への意図的に演劇的なアプローチを融合させている。その中心的な主題には、個人の自由、回復力、喜びに満ちた反逆、光と闇の均衡、そして音楽のもつ変容の力が含まれる。

## 状況

**試験的FTP実装 — v0.1**

キツネ教は、**連邦型伝統プロトコル(FTP)**の実装である。

本実装は、宗教中立的なFTPコアを、継承された伝統や再構成された歴史的伝統ではなく、新たに構築された宗教伝統に適用する試験事例として機能する。

本実装の目的は、キツネ教をFTP仕様の一部とすることではない。むしろ、独立した伝統が、自らの神話、神学、象徴、儀礼生活、および本質を保持しつつ、FTPを用いて永続的な制度を発展させうることを示すことにある。

## FTPによる制度化

キツネ教の本来の素材は、神話、神学、象徴、儀礼、および宗教的本質を提供する。

FTPは、以下のような問いに対する制度的枠組みを提供する。

- 地域の共同体はどのように構成されるのか。
- 地域の共同体にはどのような権限が属するのか。
- 連邦機関にはどのような権限を委任しうるのか。
- 役員はどのように選任され、制限され、解任されるのか。
- 教義、儀礼、および地域慣習はどのように区別されるのか。
- 紛争はどのように解決されるのか。
- 制度上の資産はどのように管理されるのか。
- 共同体は、不必要な中央集権的権威を生み出すことなく、どのように協力しうるのか。
- 伝統は、指導者や会員の交代をどのように乗り越えて存続しうるのか。

したがって、結果として生まれた制度文書は、既存のキツネ教の伝統を中心に構築された実装層である。

## 実装文書

キツネ教のFTP実装は、七つの文書で構成される。

1. **[文書I — 憲章](document-i-the-charter.md)**  
   キツネ教の憲法的基盤を定める。これには、その本質、制度上の原則、基本的な権限、および地域の共同体とより広い連邦との関係が含まれる。

2. **[文書II — 連邦プロトコル](document-ii-federation-protocol.md)**  
   自律したキツネ教の共同体が、互いを承認し、協力し、限定的な権限を委任し、連邦機関に参加する方法を定める。

3. **[文書III — 地域社規約ひな形](document-iii-local-bylaws-template.md)**  
   地域のキツネの社または共同体が、役員、手続、会員規則、意思決定の過程、および制度的継続性を確立するための、再利用可能な統治のひな形を提供する。

4. **[文書IV — 儀礼枠組み](document-iv-ritual-framework.md)**  
   地域における表現、適応、および共同体固有の実践の発展の余地を保ちつつ、本伝統の儀礼生活を整理する。

5. **[文書V — 倫理規範](document-v-ethical-code.md)**  
   キツネ教の共同体および機関への参加に伴う倫理原則と行動上の期待を定める。

6. **[文書VI — 役員手引書](document-vi-officer-manual.md)**  
   制度上の役割を託された役員の責任、制限、期待、および実務上の職務を定める。

7. **[文書VII — 紛争手続](document-vii-dispute-procedure.md)**  
   地域の自律と適正手続を尊重しつつ、対立、苦情、制度上の紛争、および統治の失敗に対処するための手続を定める。

これらの文書は、**[連邦型伝統プロトコル — 宗教中立コア v0.1](../../federated-tradition-protocol-core-v0.1.md)**、および本来の**[キツネ教原典文書](source/Kitsune-Kyo.pdf)**と併せて読まれるべきである。

これらはともに、伝統の宗教的内容と、それを組織し保存するために用いられる制度的プロトコルとの区別を示している。

## FTPとの関係

キツネ教は、**連邦型伝統プロトコル・コアの一部ではない**。

それは、同プロトコルのありうる実装の一つである。

その神学、神話、象徴、宗教上の存在、儀礼、用語、および美意識は、キツネ教自体に属するものであり、FTPの要件ではない。

逆に、FTPを実装する他の伝統は、キツネ教のいかなる宗教的内容も採用する必要はない。

この**プロトコル**と**伝統**の分離は、FTPアーキテクチャの根幹である。
