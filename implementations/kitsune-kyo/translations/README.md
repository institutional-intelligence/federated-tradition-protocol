# Kitsune-Kyō Translations

This directory contains translated editions of the Kitsune-Kyō source material and implementation documents.

Each language is maintained in its own subdirectory using the appropriate ISO 639-1 language code.

## Available Translations

- [日本語 (Japanese)](./ja/)

## Translation Structure

Each language directory may contain:

- a translated edition of the original Kitsune-Kyō source document;
- a translated version of the Kitsune-Kyō repository README;
- translations of Documents I–VII;
- a language-specific translation guide establishing terminology and translation conventions.

Translations should preserve the institutional structure and meaning of the English source while allowing natural linguistic and cultural adaptation where appropriate.

The English-language materials remain the canonical source for resolving ambiguities between translations.
